Moneyball Crypto

A numbers-first framework for finding potentially mispriced crypto protocols. It does not predict pumps; it ranks valuation discrepancies and tells you what deserves investigation.
Research tool • Not financial advice

Fair Value Calculator

How the score works

Base FV = Revenue × Comparable P/Revenue Growth factor = 0.6 → 1.4 Supply factor = 0.50 → 1.00 Final FV = Base FV × Growth factor × Supply factor MCS = Final FV ÷ Market Cap
MCS 2.0+Strong candidate
MCS 1.3–2.0InvestigatePotentially undervalued
MCS 0.7–1.3FairNo obvious edge
MCS <0.7Avoid / reviewPotentially expensive

A high score is not a buy signal. It means your assumptions imply a valuation materially above the current market cap. Check token unlocks, liquidity, revenue quality, incentives, competitors and sustainability.

Moneyball workflow

DATA → NORMALIZE → COMPARE → ESTIMATE FAIR VALUE → SCORE → INVESTIGATE → PAPER TRADE → BACKTEST → IMPROVE

The eventual production version should pull live data from reputable market/protocol data providers, timestamp every observation, store historical snapshots, account for token unlocks/dilution, and backtest the score against BTC/SOL and relevant sector benchmarks.
